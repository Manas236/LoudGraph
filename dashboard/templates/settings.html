Starting the bot

Bot.bat is in this project folder beside Dashboard.bat. Double-click it and leave it running. It handles Telegram, scheduled videos and posting after approval.

Windows Task Scheduler

  1. Open the Windows Start menu and search for Task Scheduler.
  2. Use the commands in README.md → Scheduling → Windows to create the daily produce and stats tasks, and the bot task at sign-in. Replace the example folder with this project's folder.
  3. For daily tasks, select “Run whether user is logged on or not.” For the bot task, choose “If the task fails, restart every 5 minutes.”
  4. Use either the times above or a daily produce task to avoid making two batches.

Logs are in cache/logs/pipeline.log. README.md also includes Linux cron and systemd instructions.
